# Venga downloads

This page holds the Venga Windows app installers. The app checks here for new
versions and updates itself.

**To install:** open [Releases](https://github.com/marcelormendes/venga-releases/releases/latest),
download `Venga-Setup-<version>.exe` and run it. If Windows says "Windows
protected your PC", click **More info** → **Run anyway**.

You only need to do this once. After that, Venga updates itself.
